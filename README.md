Internet Hardware Store — Интернет-магазин-техники

Полноценный интернет-магазин с админ-панелью, корзиной, оформлением заказов и двойным шифрованием данных.

Технологии:

Backend - ASP.NET Core 9.0 - Entity Framework Core - PostgreSQL - JWT Authentication - BCrypt + AES-256 шифрование - Serilog (логирование)

Frontend - React 18 - Material-UI - React Router

Функционал - Регистрация и авторизация (Admin/User) - Каталог товаров - Корзина покупок - Оформление заказа - Админ-панель - Отзывы и рейтинги - Поиск товаров - Одинарное шифрование данных

Запуск

  Frontend
    npm start
  
  Backend
    cd Backend
    dotnet restore
    dotnet run
